# 용인 우리동네 비 알림

용인시 38개 읍면동의 호우 위험 단계(평소·주의·경계)와 빗물이 모이는 곳을 3D 지형 위에 보여주는 웹 페이지입니다.
기상청 단기예보·초단기예보를 매시간 받아 동별로 평균하고, 토지피복으로 유출량을 계산합니다.

**화면 보기:** https://mimimmimi789.github.io/yongin-rain-alert/

## 폴더 구성

| 경로 | 내용 |
|---|---|
| `index.html` | 화면 (지형·토지피복·동 경계 데이터가 들어 있는 단일 파일) |
| `data/latest.json` | 최신 기상청 강우 자료. 매시간 갱신되고, 화면이 10분마다 다시 읽습니다 |
| `scripts/fetch_kma.py` | 기상청 API허브에서 용인 격자 42개 강수를 받아 동별로 평균하는 스크립트 |
| `src/` | 화면 원본 (스크립트, 스타일, 빌드 스크립트) |
| `docs/yongin-rain-alert-intro.pptx` | 소개 발표 자료 |

## 계산 방법 요약

- **동별 강수:** 기상청 5km 격자(LCC 투영)와 동 경계가 겹치는 면적으로 가중 평균
- **유출고:** SCS-CN 방법. S = 25400/CN − 254, Ia = 0.2S, Q = (P − Ia)² / (P − Ia + S). 토양군 C, 선행함수조건 II 가정
- **위험 단계:**
  - 경계: 3시간 90mm 이상, 12시간 180mm 이상, 또는 12시간 유출고 60mm 이상
  - 주의: 3시간 60mm 이상, 12시간 110mm 이상, 또는 12시간 유출고 30mm 이상
- **빗물 흐름:** 90m DEM에서 물길을 따라 각 칸의 유출량을 하류로 누적

유출고 기준은 과거 침수 기록으로 보정하기 전의 임시값입니다.

## 데이터 갱신

`fetch_kma.py`는 환경 변수 `KMA_SERVICE_KEY`에서 인증키를 읽습니다. 인증키는 이 저장소에 넣지 않습니다.

```bash
KMA_SERVICE_KEY=... python3 scripts/fetch_kma.py data/latest.json
```

## 화면 다시 만들기

```bash
cd src && python3 build_citizen.py   # site_index.html 생성 → 저장소 루트 index.html로 복사
```

## 자료 출처

기상청 API허브 단기예보 조회서비스, 환경부 토지피복도(중분류), 국토지리정보원 DEM, 행정안전부 생활안전지도(둔치주차장).

참고용 정보이며 공식 특보·재난문자를 대신하지 않습니다.
